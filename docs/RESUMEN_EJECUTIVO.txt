┌─────────────────────────────────────────────────────────────────────────┐
│ 🎯 FLUJOS OPERATIVOS (HOY FUNCIONALES)                                 │
└─────────────────────────────────────────────────────────────────────────┘

1. CLIENTA HACE RESERVA
   Inicio → Selecciona servicio + fecha/hora
   Sistema valida disponibilidad (no doble booking)
   POST /reservar → BD: Booking creado
   Notificaciones → Email + WhatsApp a clienta + admin
   Resultado → Clienta ve en /mi-cuenta

2. ADMIN CONFIRMA CITA
   /admin/login → Dashboard citas
   Ve "pending" → Botón "Confirmar"
   BD: Status pending → confirmed
   Notificaciones → Email + WhatsApp a clienta
   Auditoría → Registra quién confirmó, cuándo

3. CLIENTA REPROGRAMA
   /mi-cuenta/cita/{id}/reprogramar
   Selecciona nueva fecha/hora
   Validación de disponibilidad
   BD: Status → reschedule
   Notificación → Admin revisa en /admin/citas

4. PAGO POR TRANSFERENCIA
   Clienta ve "Anticipo: C$ 1,500"
   Transfiere al banco
   Sube comprobante (PNG/JPG/PDF)
   BD: Status pending_transfer
   Admin revisa y marca "paid"
